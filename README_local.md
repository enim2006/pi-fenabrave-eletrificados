# PI — Ciência de Dados Low Code — Fenabrave (Vendas de Veículos)

Pasta de trabalho pessoal (assistida por IA) para o Projeto Integrador do 2º semestre — ADS EAD Senac SP.
Tudo relacionado a este PI deve ficar dentro desta pasta.

## Fluxo do projeto

1. **01_dados_brutos/** — Coloque aqui os PDFs originais da Fenabrave (emplacamentos, vendas por marca/modelo/UF etc.), sem editar.
2. **02_dados_extraidos/** — Dados extraídos dos PDFs em formato tabular (CSV/Excel), prontos para análise.
3. **03_exploracao/** — Análise exploratória: scripts, notebooks, anotações, gráficos e primeiras descobertas sobre o que os dados contêm.
4. **04_power_bi/** — Arquivos do Power BI (.pbix) e exports do dashboard, quando o projeto avançar para essa fase.
5. **05_documentacao/** — Enunciado do PI, critérios de avaliação, cronograma, atas de reunião do grupo e outras referências.
